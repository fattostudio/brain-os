# Poco

## Hypotheis

Today’s communication system is built on the premise that we can have all the information that we want all the time.
Poco disputes this and sets out to create an information system based on less information and, only at certain times.

Everything, all the time > something, sometimes


## Why

The systems that we developed to distribute, search and create information are focused on ensuring the continuous growth of those same systems.

These systems are not focused on user needs, they are focused on user weaknesses, in particular on the brain’s propensity to be distracted.
Distraction is the fuel that these systems run on.
We have created technologies that trick humans into being distracted to power a supply and demand economy of endless information.

## How

Categorizing, prioritizing and pacing all incoming, outgoing and requested information to and from us.

### Categorize

Let’s be clear that what we have today is not a system that is truly based on our needs, like I said before the systems are based on the needs of the services that we use, which are to increase usage so that they can make more money. An example? Any given person has at least 4 or 5 messaging services running at the same time. We hop between services based on who we talk to. This is not user centric, a user centric approach would be to have one messaging service that collects information from all the services and serves them through one unified experience.

So the first thing that we have to do is to remove this unnecessary and profit centered layer by categorizing all the objects that we interact with based on what they are and what they do for us.

The digital objects that we interact with can be grouped in
Media (Images, Videos, Audio, Articles) - Communication (Messages, Emails, Calls) -  Management (Finances, Bookings, Shopping, Calendars - Events, Tasks) - Maps (Locations, Itineraries) -  Contacts (People, Businesses).

### Prioritize

The problem that we have with distraction is this constant multi-tasking, context switching mechanisms where everything has the same importance because everything can be a hook to make the user engage with something else, which will then be a hook to the next thing and so on. Again this is not how humans function, everything is not the same, multi-tasking and context switching is not the only way in which we can function. How do we implement a filtering system that allows the user to focus on a limited number of important pieces of information at a time and more importantly how do we close the system so that it doesn’t constantly present opportunities to distract the user into the next thing.

### Pace

Three daily editions to deliver new information and search results. Morning edition, Afternoon edition, Evening edition.
